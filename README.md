# measure_device ROS 2 port

This archive contains a ROS 2 / Bookworm-friendly port of the original ROS 1 `measure_device` package.

Packages included:
- `measure_device` — ROS 2 Python node package
- `msgs` — ROS 2 interface package containing `E720.msg`

If your workspace already has a shared `msgs` package, keep the existing one and copy only the `E720.msg` definition if needed.
