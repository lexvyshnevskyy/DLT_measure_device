# measure_device

E7-20 impedance meter over serial. Publishes `msgs/E720` on `/e720` for core sensor fusion.

Active when `DELATOMETRY_MEASURE_SOURCE=e720` (Web UI **Configuration**). E7-20 frequency sweeps in the program wizard use this node.
